# Tekken 6 Native Linux — Beta 0.4

Native Linux beta with Vulkan rendering, standalone launch support, and the
Scenario Campaign timing and performance fixes.

## Download and play

[Download the prebuilt Linux archive from MediaFire](https://www.mediafire.com/file/i8rmps55m18hoab/Tekken6-Linux.tar.xz/file)

The prebuilt download is for players who do not want to compile the port.
Extract the entire archive, open a terminal in the extracted app folder, and run:

```sh
./Play.sh
```

For fullscreen, use `./Play.sh --fullscreen`. Keep the complete folder together;
the launcher loads the bundled runtime libraries. Saves and shader caches stay
inside the app folder. Back up your existing saves before replacing an older
app folder. F3 toggles the FPS display.

## Requirements

- x86-64 Linux with an FMA3-capable CPU.
- A working Vulkan GPU driver.
- glibc 2.38 or newer and libstdc++ providing `GLIBCXX_3.4.32` or newer.
- X11/Wayland runtime libraries and Bash.

Tested on Zorin OS 18.1, Linux 7.0, Ryzen 5 5500, RX 580 2048SP 8 GB,
16 GB DDR4, and Mesa RADV 25.2.8. Other distributions and GPUs need further
testing. This build still depends on compatible system libraries.

## Changes and testing

- Native Linux Vulkan framebuffer rendering with build and launch scripts.
- Corrected 60 Hz guest timing and faster Linux memory-protection queries.
- The reproduced Scenario Campaign stage now has visible scenery, gameplay
  near 60 FPS, and normal cutscene speed.
- Practice remained near 60 FPS at normal speed. The tester also reported
  steady 60 FPS on the storm stage and Mystical Forest, which previously slowed
  down. These are player observations rather than repeated benchmarks.
- The in-game player name follows the Linux account username; existing save
  profile identity is preserved.
- Optional profiling tools and standalone app-folder packaging.
- Memory-protection, POSIX wait, launcher, profile-name, and profile-parser
  regression checks passed during development.

## Known limitations

- Campaign testing covers one reproduced stage, not the complete story or every
  cutscene. Remaining stages, including previously slow snow/Manji Valley
  scenes, still need follow-up testing.
- The fast memory-query path requires kernel support available in Linux 6.11+.
  Older kernels automatically use the original parser and may perform worse.
- Vulkan framebuffer rendering is the tested path on this GPU. The optional
  fragment-interlock path selected software rendering on the test machine.
- Online multiplayer support is not included in this Linux beta.

## Source and feedback

The source for this release is available under the `v0.4-Beta` tag in this
repository. To build from source with your own supported Xbox 360 ISO, follow
the Linux instructions in the repository README.

The upstream Linux port is tracked in
[PR #20](https://github.com/mahmoud-mess/tekken6-recomp/pull/20), related to
[Linux support issue #10](https://github.com/mahmoud-mess/tekken6-recomp/issues/10).

For bug reports, include your distribution and kernel, CPU, GPU and driver,
game mode and stage, observed FPS, and reproduction steps. Use `./Play.sh --log`
to create a log under the app folder's `logs/` directory.
